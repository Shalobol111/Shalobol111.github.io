# Налоги и право

Адаптивный сайт бухгалтерских услуг. Статическая версия в `dist/` подходит для закрытого предпросмотра. Сервер `server.mjs` обслуживает ту же страницу и отправляет заявки в рабочем режиме.

## Локальная проверка

Требуется Node.js 22 или новее.

```sh
npm ci
npm test
npm start
```

Откройте адрес из строки Local. В режиме предпросмотра форма проверяет поля без отправки письма.

## Рабочая форма

Разверните Node.js за HTTPS-прокси, который обслуживает тот же домен. Заполните файл окружения по `.env.example`. Укажите `LEADS_MODE=live`, точный HTTPS-адрес в `PUBLIC_ORIGIN`, параметры авторизованного SMTP и допустимый адрес отправителя. Адрес получателя по умолчанию — `nalogi.pravo26@gmail.com`. Включайте `TRUST_PROXY` только при перезаписи заголовка X-Forwarded-For доверенным прокси. Ограничитель запросов действует на один серверный процесс.

```sh
npm ci --omit=dev
node --env-file=.env server.mjs
```

Перед публичным запуском замените временные сообщения на странице документов ссылками на актуальную оферту и политику. Ссылки на PDF с действующего сайта возвращают HTTP 404. Сверьте документы и текст согласия с выбранной инфраструктурой и проверьте получение письма на рабочей почте, отправив заявку с вымышленными данными.
